## 📊 О проекте

**ABSOLUTE ULTIMATE TRADING BOT** — это профессиональный торговый бот для криптовалют, который использует **нейросетевой анализ** (RSI, MACD, Bollinger Bands) для принятия решений. Бот полностью автоматизирован, имеет веб-интерфейс и Telegram-управление.

### 🔥 Ключевые особенности

| Особенность | Описание |
|-------------|----------|
| **🧠 Нейросетевой анализ** | RSI + MACD + Bollinger Bands для точных сигналов |
| **🎯 Трейлинг-стоп** | Нет фиксированного тейк-профита! Продажа только при падении от максимума |
| **📊 49 монет** | Топ-49 ликвидных криптовалют |
| **🌐 Веб-интерфейс** | Красивый дашборд с графиками и управлением |
| **📱 Telegram бот** | Управление и уведомления со смартфона |
| **🛡️ Защита капитала** | Стоп-лосс, тейк-профит, дневной лимит |
| **💰 Бесплатно** | Полностью открытый код, никаких подписок |

## 🚀 Быстрый старт

### Требования
- Python 3.11+
- Аккаунт на MEXC (или любой бирже с API)
- Telegram (опционально)

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/UDabranski/absolute-trading-bot.git
cd absolute-trading-bot

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить API ключи
# Создайте файл .env и добавьте:
# MEXC_API_KEY=ваш_ключ
# MEXC_API_SECRET=ваш_секрет

# 4. Запустить бота
python ULTIMATE_BOT_FIXED.py
