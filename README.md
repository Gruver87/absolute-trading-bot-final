# Спот-бот MEXC

Суммы котировки хранятся в satoshi: `1 USDT = 1_000_000`, тот же множитель, что `SATOSHI_MULTIPLIER` в experimental `runtime/amount.py`. Float на этом пути отвергается. Цепь DUP бот не импортирует. Режим `liquidity` дополнительно сверяет цену с Binance и Bybit и ставит целочисленную оценку. Покупка не проходит, если второй площадки нет или цены разошлись больше чем на 30 bps. Это не нейросеть и не прогноз. Горячая оценка может считаться в `native/` (Rust); пока dll нет, считает Python и пишет это в лог.

Взято из старой папки `Торговля`:

- вход старого цикла: RSI ниже 35
- подтверждение, которое в старом коде было написано и не вызывалось: нижняя полоса Боллинджера или свежий пересечение MACD вверх
- выход: стоп 3.5%, тейк 7%, трейлинг с +3% и откат 2%

Не взято: ключи из исходников, Flask-панель, фьючерсы, кросс-чейн «мост», функция с именем machine learning (это две скользящие средние).

По умолчанию бумажный счёт в `data/book.json`. Ордер на биржу уходит только если в `.env` стоит `SPOT_LIVE=1` и процесс запущен с `--live`.

```powershell
cd C:\Users\vovun\Desktop\Торговля
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
.\.venv\Scripts\python -m spotbot --once
```

Повтор без `--once` крутит цикл раз в 60 секунд. Это не обещание прибыли.

Режим `liquidity` смотрит пары USDT, у которых за сутки объём уже заметен и ход от +0.5% до +12%. Покупка только если последняя закрытая 5-минутная свеча дала объём хотя бы вдвое выше медианы предыдущих и закрылась в верхней части диапазона, а в стакане нотионал покупок больше продаж. Цель продажи ставится на +2.5% сразу. Если при плюсе заявки на продажу становятся больше покупок, позиция закрывается раньше. Стоп 1.5%. Счёт пишется в `data/book_liquidity.json` и не смешивается с режимом RSI.

```powershell
.\.venv\Scripts\python -m spotbot --mode liquidity --once
```

Этот режим не видит будущее. Всплеск объёма часто заканчивается откатом. Сетка и усреднение сюда не входят: на тонких парах они копят монету в падении.
